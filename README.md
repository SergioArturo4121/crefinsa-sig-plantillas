# 📄 CREFINSA – Sistema Integrado de Gestión (SIG)
## Repositorio Oficial de Plantillas Institucionales

Este repositorio contiene las **plantillas oficiales del Sistema Integrado de Gestión (SIG)** de CREFINSA, así como los **instaladores automatizados** para su despliegue en equipos del personal.

---

## 📁 Contenido del repositorio

### 1. Plantillas Institucionales
Ubicadas en la carpeta:
/plantillas/
Incluye:
- Plantilla Maestra de Procedimiento Integrado
- Plantilla Maestra de Instructivo
- Plantilla Maestra de Política
- Plantilla Maestra de Formatos SIG

---

### 2. Instaladores Automatizados
Ubicados en:
/instaladores/

Los instaladores permiten:
- Descargar automáticamente la plantilla desde el SIG
- Instalarla en la ruta oficial de Microsoft Word:
%APPDATA%\Microsoft\Templates

- Garantizar que Word la muestre en:
**Archivo → Nuevo → Plantillas personales**

---

## 📦 Releases Oficiales

Las versiones estables de instaladores y plantillas se publican en:
